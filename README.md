# Ramadan Sales Analysis - Excel Project

## Tools Used
Microsoft Excel, PivotTables, Charts, VLOOKUP, Conditional Formatting

## Project Overview
Analyzed 1 month of sales data during Ramadan to identify top-selling products, peak hours, and revenue trends.

## Key Insights
- Top 5 products generated 45% of total revenue
- Peak sales hours: 6PM - 10PM 
- Week 3 of Ramadan had 30% higher sales than Week 1
## Excel Skills Used
- PivotTables for data summarization
- Data Visualization with Bar and Line Charts  
- Data Cleaning and Conditional Formatting
- KPI Dashboard creation
